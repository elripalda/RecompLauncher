# RecompLauncher 0.90 Beta 13

- **Proton improvements.** GE-Proton installs are more reliable, and Windows recomps are easier to get going on Linux and Steam Deck.
- **Safer cloud saves.** Smarter backups and restores, and saves now carry over between Windows, Linux and Steam Deck.

- **Better game detection.** The right program gets picked more often, with clearer help when something's off.
- **Visual C++ in one press**, and one more recomp joins easy setup.
