# RecompLauncher 0.90 Beta 27

- **Recomps hosted on SourceForge** install and update like any other, checked before they go in. — Added by @elripalda.
- **Cloud saves in your hands.** The Saves tab shows when your save last went up and from where, with Upload Now and Check Again, also in Big Picture. — Added by @elripalda.
- **Great on Handhelds.** Games handheld players say run well get a label and a filter in Discover and Big Picture. — Added by @elripalda.
- **Game setups update on their own.** Fixes to how a game starts and sets up reach you without a launcher update. — Improved by @elripalda.
- **Coming soon games** can link to where they're being shared. — Added by @elripalda.
- **The quick menu loads only when you open it**, so the launcher uses less memory. — Improved by @Element20Three ([#35](https://github.com/elripalda/RecompLauncher/pull/35)).
- **General fixes and optimization**, including better picks for releases that only come as an installer. — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
