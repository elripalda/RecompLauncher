# RecompLauncher 0.90 Beta 46

- **Coming from another launcher? One window brings your games across, and they update from here after that.** — Added by @elripalda, from the Ideas board.
- **Discover lists games or recomps, spreads out on wide windows, and shows console and system icons in its lists.** — Added by @elripalda, from the Ideas board.
- **When a better version of a game you have is out, its page says so and switches you over in one step.** — Added by @elripalda, from the Ideas board.
- **Easy Setup makes a plain copy of a compressed game image itself: CHD, CSO, ZSO and the GameCube and Wii formats.** — Added by @elripalda, from the Ideas board.
- **Developers can offer setup options, such as DLSS or FSR 4, and the launcher remembers what you picked.** — Added by @elripalda.
- **The versions list makes the recommended version stand out and marks installed versions and verified developers.** — Improved by @elripalda, from @Xarishark's ideas.
- **Update notes in Downloads History show tables and note boxes, with a short preview and Show All.** — Improved by @elripalda, from @Xarishark's report.
- **Games built from your copy start the program you picked, and are built again if the built game was moved away.** — Fixed by @elripalda, from @artik's report ([#168](https://github.com/elripalda/RecompLauncher/issues/168)).
- **Games that start with Python find it, and say what to install when it's missing.** — Fixed by @elripalda.
- **On Linux, the launcher shows up in headless Wayland sessions by drawing through XWayland.** — Fixed by @elripalda.
- **Share Saves Between Versions works for games that save more than one file.** — Added by @Lui35 ([#115](https://github.com/elripalda/RecompLauncher/pull/115)).
- **Games a folder scan found stay in your Library when your account's list is read.** — Fixed by @thehobbit85 ([#133](https://github.com/elripalda/RecompLauncher/pull/133)).
- **Settings and lists from another launcher are read even when they start with a byte-order mark.** — Fixed by @thehobbit85 ([#132](https://github.com/elripalda/RecompLauncher/pull/132)).
- **General improvements and fixes.** — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
