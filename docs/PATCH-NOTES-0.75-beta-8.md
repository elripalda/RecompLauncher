# RecompLauncher 0.75 Beta 8

Fixes from your Beta reports.

- **Recomps with their own installer or setup.** Some recomps come as an installer (Madden NFL 08) or need their own setup run once before the game (Tenkaichi 3). The first time you press Play, that setup opens for you. Follow its steps and the game is ready. For an installer, the launcher finds where the game went and plays it from there, with the options its shortcut uses.
- **The right program for games with a launcher.** Games that ship their own launcher next to the engine now start through it. CTR Nitro-Fueled opens its launcher, and Crash Bandicoot PC is found properly.
- **Launch scripts.** When a release starts its game with a script named for it, like "Launch Madden NFL 08", the launcher uses that so the game gets its options.
- **Games that need your files passed to them.** When a recomp shows how it wants to be started (like Smash 4), the crash window explains it and takes you straight to its Launch options.
- **The crash window says when your copy is the wrong version.** If a game says your copy doesn't match (a different region or revision), the window tells you to check which version its developer needs.
- **New builds show up sooner.** While the launcher is open, a new version pops up a few minutes after it's out, so you don't have to restart to find it.
- **Closing a game's console window isn't a crash.** Quitting a game by closing its console no longer opens the crash window.

Already installed one of these? Just press Play: the launcher checks it again the first time.

One-click setup is coming game by game. We're working with each recomp's developer to get their game ready for it, so some will still need a step or two from you for now. Thanks for bearing with us. Every build gets closer.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
