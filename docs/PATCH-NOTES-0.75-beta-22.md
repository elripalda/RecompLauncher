# RecompLauncher 0.75 Beta 22

- **Report a Problem.** A new page in Settings sends a bug, an idea or your thoughts straight to us. Pick the game it's about and its last log goes along. It's in every game's right-click menu too.
- **Better crash reports.** Send It to Ripalda is always there when a game closes. Add a sentence about what you were doing, and the report includes how the launcher started the game and how it was set up, so problems get found much faster.
- **Error codes explained.** The crash window says what a code means, like a missing DLL or an access violation, not just the number.
- **Blocked by Windows.** When Smart App Control stops a game, the crash window says so and opens Windows Security for you.
- **The right program for your copy.** When a recomp has a program for each version of a game and the wrong one started, Choose Program is right there.
- **Big Picture file browser.** Long folders and the list of places scroll with you, and Y opens Options to copy, cut and paste, so you can move a disc image into your games folder right from the couch.
- **Covers after Big Picture.** Leaving Big Picture mode brings every cover and wide tile back right away.
- **Show Game Names.** Settings → Appearance can name every recomp after its game, like Tears of the Kingdom instead of TotK Recomp.
- **Portable mode (beta).** Settings → General → Make a Portable Copy puts RecompLauncher on a portable drive with your library, settings, play time and save backups, ready to use on any PC.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
