# RecompLauncher 0.8.1

## By the clock

- Closing the window keeps RecompLauncher running next to the clock, like Steam or Discord. Click
  its icon to bring the window back.
- Right-click the icon for your recent games, Library, Discover, Screenshots, Settings, Big Picture
  mode and Quit.
- Don't want it? Turn off "Keep running by the clock" in Settings, under General.

## Fixes

- The window opens again after you minimize it.
- Uses much less of your PC while it's minimized or by the clock.
- Settings no longer flicker. Picking a section only changes the right side, and nothing moves on
  its own while you're there.
- Changing a setting in Big Picture mode no longer redraws the panel beside it.

## Installer

- Running the installer when RecompLauncher is already there shows Update, or Repair when it's the
  same version, with Uninstall under it.
- The uninstaller has the new look. You can also delete the launcher's settings and game list while
  you're there. Your game folders and saves are never touched.
- A launcher that's running closes on its own when you update or uninstall.

## More

- Add to Steam and Add to desktop are on every installed game's page, next to GitHub and Report a
  problem.
- Settings → About has a Discord button, Reset settings, and a way to run first-time setup again.
  Your games, saves and library folders stay.

Thanks for testing. If something breaks, send the log from the crash screen or a report from the
game's page; every one helps.
