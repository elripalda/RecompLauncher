# RecompLauncher 0.90 Beta 14

- **Ready to Play.** Recomps that set themselves up now come first, with their own row on Home. — Added by @elripalda.
- **Cleaner game pages.** Easy Setup leads, and the AI-assisted tag is an option in Settings → General. — Improved by @elripalda.
- **Smarter downloads.** The right build for your PC gets picked more reliably, and updates follow the recommended version. — Improved by @elripalda.
- **Faster ROM scanning.** Each folder is read once, and linked folders and files are followed once. — Improved by @elripalda.
- **Extracted game detection.** Extracted games, including PS4 game folders, are recognized as one entry, regardless of filename case. — Added by @Xarishark ([#17](https://github.com/elripalda/RecompLauncher/pull/17)).
- **Play Both.** Start another game while one is already running. — Added by @elripalda.
- **Linux and Steam Deck improvements.** Better hardware detection, and a new Graphics Mode in Settings → Appearance for a smoother window. — Added by @elripalda.
- **Clearer crash help**, including when a mod is the cause. — Improved by @elripalda.
- **General fixes and optimization** across setup, updates and game detection. — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
