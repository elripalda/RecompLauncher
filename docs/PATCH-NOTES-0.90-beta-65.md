# RecompLauncher 0.90 Beta 65

**This is a beta.** Things may change or break while we're in beta. Thanks for your patience.

**Heads up:** this release reworks how games install, update and build. Some games with a build step may ask you to set them up again. Sorry about that, it was needed to move to the new system.

- **Easy Setup keeps your choices, and each game has its own setup mode.** — Improved by @Xarishark ([#307](https://github.com/elripalda/RecompLauncher/pull/307)).
- **Game updates go in whole or leave the game as it was.** — Fixed by @Xarishark ([#303](https://github.com/elripalda/RecompLauncher/pull/303)).
- **Cloud save status for each game, and saves only come from folders the game is known to use.** — Added by @Xarishark ([#289](https://github.com/elripalda/RecompLauncher/pull/289), [#304](https://github.com/elripalda/RecompLauncher/pull/304)).
- **Settings can turn off the featured banner, so Home starts at Jump back in.** — Added by @Xarishark ([#306](https://github.com/elripalda/RecompLauncher/pull/306)).
- **Game pages say where their stars come from: GitHub, GitLab or Forgejo.** — Added by @Xarishark ([#300](https://github.com/elripalda/RecompLauncher/pull/300)).
- **Fixes for games built from your own copy, and game counts that count games.** — Fixed by @Xarishark ([#302](https://github.com/elripalda/RecompLauncher/pull/302), [#308](https://github.com/elripalda/RecompLauncher/pull/308), [#288](https://github.com/elripalda/RecompLauncher/pull/288)).

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
