# RecompLauncher 0.90 Beta 24

- **Games with more than one disc.** Easy Setup can now ask for each disc, optional DLC, and the keys a game needs, and remembers shared keys for the next game that uses them. — Added by @Xarishark ([#22](https://github.com/elripalda/RecompLauncher/pull/22)).
- **Linux AppImages set themselves up.** A game can carry its setup inside its AppImage, so it plays and its settings work from the launcher straight away. — Added by @Xarishark ([#12](https://github.com/elripalda/RecompLauncher/pull/12)).
- **Lighter when idle.** The launcher rests when it isn't in front, and the AppImage draws much faster on Linux. — Fixed by @Element20Three ([#28](https://github.com/elripalda/RecompLauncher/pull/28)).
- **Credits in the notes.** Contributors' names in these notes link to their GitHub pages. — Added by @Xarishark ([#31](https://github.com/elripalda/RecompLauncher/pull/31)).
- **Smarter crash help** for blocked files and graphics drivers, and the right program picked more often. — Improved by @elripalda.
- **General fixes and optimization.** — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
