# RecompLauncher 0.75 Beta 13

- **Game settings, right in the launcher (Beta).** Over 200 recomps now have a Game settings tab: resolution, full screen, frame rate, V-Sync, screen shape, anti-aliasing and more, depending on the game. Pick a setting and it's saved straight into the game's own settings file, so it matches the game's own menus and its own launcher.
- **Your picks stay through updates.** When a game updates, the settings you chose come along with it.
- **Ready when the game is.** Some games create their settings file the first time they start. Their settings unlock after that first play.
- **Smoother, steadier screens.** Pages now update in place. Finishing an update, switching a setting or refreshing Discover no longer redraws the whole page, so no more flicker and no jumping back to the top.
- **Easy Setup** gets its proper name across the launcher.
- **More to come.** Settings are being added game by game, and this first round is marked Beta while we keep polishing it.

If a setting doesn't look right in game, send a log from the crash window or Settings → Beta. That's how this gets better fast.
