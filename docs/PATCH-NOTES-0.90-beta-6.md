# RecompLauncher 0.90 Beta 6

- **Smoother everywhere.** Scrolling your Library, opening game pages and folding the sidebar are lighter and faster, on the Steam Deck and Linux most of all. Big lists only draw the games you can see.
- **Out of the way while you play.** While a game runs, the launcher stops its animations and checks the controller less often, so the game gets the power.
- **Steam Deck: Add to Steam.** From Desktop Mode it closes and reopens Steam properly, and the launcher opens in Gaming Mode.
- **Windows recomps on Linux.** When the launcher finds Proton or Wine, Windows-only recomps show up and play through it. You can turn it off in Settings → General.
- **Smarter Check the Details.** Add From GitHub keeps the project's own name and fills in the game it's for, and the art follows the game name as you type it. Pick other art from the cover, the background or Choose Art.
- **Know the game behind your folders.** Folders you add get the game they're for from their README or name, so Show Game Names works for them too.
- **Troubleshoot knows more.** It spots a folder path with letters some games can't read, and a game saying it can't find its files. When a game closes right as it starts, the crash window leads with Troubleshoot.
- **Clearer download errors.** They say which site had the problem and what it means.
- **Faster big downloads.** Large files from sites that allow it come down in four pieces at once.
- **Time to update.** If you're a few versions behind, the launcher tells you when it opens.
- **Plugins can do more.** They can unpack .rar files, show a tab on game pages, open links in your browser and have their own settings. In Settings → Plugins you choose where a plugin's downloads go and whether it asks before each one.
- **Little things.** Updates Ready rows open the game's page, and the console picker in Add From GitHub is easier to use.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
