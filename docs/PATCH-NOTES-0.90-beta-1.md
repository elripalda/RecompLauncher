# RecompLauncher 0.90 Beta 1

- **RecompLauncher on Linux.** An AppImage that runs on most distros and a .deb for Debian, Ubuntu and Mint. The AppImage updates itself.
- **Windows recomps on Linux.** Turn on Settings → General → Play Windows Recomps With Proton and recomps that only have a Windows version install and play through Proton. Steam's Proton, GE-Proton, umu-launcher and Wine are found on their own.
- **Looks on Linux.** Sharp, Vivid, Film and CRT work on Linux through vkBasalt. Install it from your distro's packages and pick a look like on Windows.
- **Add From GitHub.** Paste a recomp's GitHub link in the Library and it's added, ready to install and keep up to date, even when it isn't in Discover yet.
- **Installed filter.** The Library can show only the games you have installed.
- **Opens On.** Settings → Appearance can open the launcher on your Library instead of Home.
- **The window remembers.** RecompLauncher opens at the size and place you left it, and the maximize button shows when it's maximized.
- **Looks that start every time.** When a game crashes right away with a look on, the next start tries ReShade another way and keeps the one that works.
- **The right download.** Recomps that also put out a server for online play install the game, not the server.
- **Clearer crash window.** It now explains when a game stopped responding and Windows closed it, and when a game shut itself down after a fatal error.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
