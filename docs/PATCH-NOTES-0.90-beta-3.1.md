# RecompLauncher 0.90 Beta 3.1

Some of you got a virus warning from Windows Security after Beta 3. Sorry about that. It was a false positive, and this update is the fix.

- **Fewer false virus warnings.** RecompLauncher now asks Windows for what it needs directly, and we cleaned up the wording that antivirus tools were misreading.
- **Sign-in kept by Windows.** Your sign-in now lives in Windows' Credential Manager. Sign in once more after updating.
- **Installs that hang on.** If Windows or an antivirus is holding a file while a game installs, the launcher waits and tries again.
- **Admin prompts that show up.** Game uninstallers that need administrator rights now get Windows' prompt.

We're in the process of getting RecompLauncher officially signed, so these warnings should be gone in the coming days.

Thank you for your patience, and for being part of the RecompLauncher family.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
