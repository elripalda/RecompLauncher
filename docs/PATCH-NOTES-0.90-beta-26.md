# RecompLauncher 0.90 Beta 26

- **Downloads you control.** Pause and resume, set a speed limit, and let downloads slow down while you play. — Added by @elripalda.
- **A smarter crash window.** Fixes other players found, a heads-up when a version is crashing for a lot of players, a one-press way back after a bad update, and a quicker way to report a game's own problems to its developer. — Added by @elripalda.
- **Check your copy first.** Easy Install games can check your copy before anything downloads. — Added by @elripalda.
- **Recomps that come as an installer** get a guided Set Up on Windows. — Added by @elripalda.
- **Finds the games your emulators know about**, on first start and in Settings. — Added by @elripalda.
- **Switch 2 .nup packages** are recognized. — Added by @Xarishark ([#38](https://github.com/elripalda/RecompLauncher/pull/38)).
- **Discover opens at once**, even with hundreds of recomps. — Improved by @Element20Three ([#36](https://github.com/elripalda/RecompLauncher/pull/36)).
- **Clearer setup labels** in Developer Tools and on game pages. — Improved by @elripalda.
- **General fixes and optimization**, smoother drawing on Mac, and Discover moves up in the sidebar. — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
