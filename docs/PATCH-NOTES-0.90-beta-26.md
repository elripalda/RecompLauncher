# RecompLauncher 0.90 Beta 26

- **Downloads you control.** Pause and resume any download, set a speed limit, and let downloads slow down by themselves while you play. — Added by @elripalda.
- **Known fixes on the crash window.** When other players found a fix for the same problem, the crash window shows it first. — Added by @elripalda.
- **Broken update warnings.** If a new version is crashing for a lot of players, the launcher says so before you update and offers the version that worked. — Added by @elripalda.
- **Go back after a bad update.** A game that crashes right after updating gets a one-press way back to the version you had. — Added by @elripalda.
- **Check your copy first.** Easy Install games can check your copy before anything downloads, then set up as soon as the download is done. — Added by @elripalda.
- **Finds games your emulators know about.** On first start and in Settings, the launcher can add the game folders your emulators already use. — Added by @elripalda.
- **Switch 2 .nup packages** are found and recognized. — Added by @Xarishark ([#38](https://github.com/elripalda/RecompLauncher/pull/38)).
- **Clearer crash help.** Run Setup for games that say which setup program they need, and Report to the Developer for problems inside the game itself. — Improved by @elripalda.
- **Clearer setup labels.** Developer Tools describes how a game is set up and what it can do, and game pages show who maintains a game's setup. — Improved by @elripalda.
- **Discover is second in the sidebar**, with a new search icon. — Improved by @elripalda.
- **General fixes and optimization**, including smoother drawing on Mac. — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
