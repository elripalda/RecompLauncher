# RecompLauncher 0.90 Beta 10

- **New Customize window.** Right-click a game and pick Customize to change its name, cover, background, logo and icon in one place. Grab art from SteamGridDB (with your own free key) or use your own picture, then drag and zoom it inside the real frame and see how it looks before you save. Works for every game, not just the ones you added yourself.
- **Your art goes everywhere.** Add to Steam and desktop shortcuts now use your custom cover, background, logo, icon and name, on Windows, Linux and Steam Deck. On Windows the game's window and taskbar pick up your icon while it runs too.
- **Smoother right-click menus.** Submenus open on hover now, right next to the menu.
- **Pick Linux or Windows.** On Linux, when a game has both a Linux build and a Windows one that runs through Proton, the launcher asks which one you want the first time.
- **Windows setups on Linux.** A game whose setup is a Windows program now runs it through Proton instead of failing.
- **No more setup loops.** After a game's own setup finishes, the launcher asks which program actually starts the game, so it won't keep opening the installer.
- **More downloads work.** Releases packed as .rar, and Windows builds packed as .tar.gz, install now. If a game's newest release has no build in it yet, the launcher grabs the latest one that does.
- **Found the wrong copy?** If the launcher found the wrong file for a game in your folders, hit Not This One on its page and pick the right one.
- **Launcher updates go through.** Updating from inside the launcher no longer gets stuck on "Copying RecompLauncher". There's also an Update RecompLauncher button in the sidebar when a new version is out.
- **Better crash help.** The crash window now spots when your PC ran out of memory, or when a game needs a command that isn't installed, and tells you what to do.
- **Fixes.** Pages no longer go blank while a game is running, and a found copy tucked one folder deeper gets picked up during setup.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
