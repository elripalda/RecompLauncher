# RecompLauncher 0.75 Beta 5

New from your Beta reports.

- **Screenshots on game pages.** A game's page shows screenshots from its developer when there are some. Click one to see it big, and use the arrow keys to flip through.
- **Add a whole Games folder at once.** In Add games you have, pick the folder that holds your recomps and the launcher finds each one inside it.
- **Search in long lists.** Lists with lots of choices, like Which recomp is this? and Console, have a search box at the top. Start typing to narrow it down.
- **The crash window catches more missing game files.** It now also names missing data files like .szs, .arc and .pak, and tells you to put your game files where the developer says.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
