# RecompLauncher 0.75 Beta 7

Fixes from your Beta reports.

- **Games that need their setup run first.** When a recomp says to run its own setup to unpack the game from your copy (like Tenkaichi 3), the crash window has a Run its setup button that opens it for you.
- **Games that need your files passed to them.** When a recomp shows how it wants to be started (like Smash 4 or CTR Nitro-Fueled), the crash window explains it and takes you straight to its Launch options.
- **The crash window says when your copy is the wrong version.** If a game says your copy doesn't match (a different region or revision), the window tells you to check which version its developer needs.
- **Closing a game's console window isn't a crash.** Quitting a game by closing its console no longer opens the crash window.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
