# RecompLauncher 0.75 Beta 21

- **Tears of the Kingdom is fixed.** Play opens its setup, waits for it to finish building the game, and starts the game from wherever you installed it.
- **Game updates.** Recomps that need the game's update ask for it right after your disc, check that it's the right one, and put it where the game reads it. It's in Big Picture mode too, and in each game's settings.
- **Game fixes.** Recomps that come as an installer now always open their setup on the first Play, wait until it's completely finished, and then start the game it builds, wherever you told it to install.
- **Find any game's program.** Choose Program sits right under Launch Options in a game's Manage tab and in its right-click menu, so you can point Play at the game wherever it lives. When a game's own setup put it somewhere the launcher can't see, it asks you where it went, and picking that folder in Add Games You Have connects it too.
- **Launcher updates.** Updating RecompLauncher leaves your desktop and Start menu shortcuts just the way you have them.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
