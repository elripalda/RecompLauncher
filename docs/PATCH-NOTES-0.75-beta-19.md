# RecompLauncher 0.75 Beta 19

- **Add to Library.** Install is now Add to Library. Add any recomp to your Library without downloading it, and the button turns into Install right where you are. Added games wait in your Library under Not Installed until you're ready.
- **Cover Flow.** Opening a game from Cover Flow is smooth and clean every time.
- **Desktop shortcuts.** A game's desktop shortcut now starts the game directly, so front ends like RetroBat and Playnite pick it up properly. Prefer it through the launcher? Turn it on in Settings → Desktop Shortcuts.
- **Search and Sort & Filter in Big Picture mode.** Find any game by name, sort the list, or narrow it down by console.
- **Optimization improvements.** Big Picture mode is faster and smoother, especially Discover and big Libraries.
- **Game fixes.** Disc-based games set up properly the first time and don't ask for your copy again, plus more installation fixes.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
