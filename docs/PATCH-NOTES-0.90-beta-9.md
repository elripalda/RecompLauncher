# RecompLauncher 0.90 Beta 9

- **Way faster browsing.** Opening Discover with the full list, and coming back to it from a game's page, is many times quicker. Long lists only size up the titles you can actually see.
- **Installs work when the site is down.** If recomplauncher.com can't be reached, the launcher gets a game's releases straight from GitHub, so you can still install and update.
- **Lighter checks.** The game list and release info only download again when they've actually changed, and covers come in at the size they're shown.
- **Game pages load ahead.** Rest the pointer on a game and its page starts loading, so it's ready when you open it.
- **Cloud saves between Windows and Linux.** A Windows game played through Proton on Linux now backs up and restores its saves in the right place, so the same save follows you between your PC and a Linux handheld.
- **File picker fix.** On folders with lots of files, the Cancel and Choose buttons stay on screen.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
