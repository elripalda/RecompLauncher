# Correcting a project's match

In **Bring Your Recomps**, check the suggested project before adding a folder.
Use **Change…** to search by project name or repository, or select **Keep untracked**.
Unmatched folders have the same picker under **Choose project…**.

For an installation already in the Library, open its game page and choose
**Manage > Project association > Change…**. The same picker is available in its
context menu under **Manage > Project association…**.

Choosing a project changes where update checks look. It does not download or
replace game files. Automatic updates are turned off when the association changes;
enable them again only when the selected project is the one you want.
**Keep untracked** stops update checks for that installation.

The installation's folder, selected program, manual launch settings, play history,
custom artwork, favorites and local save backups are retained. Existing launcher
shortcuts continue to work. Cloud saves require a new opt-in for the new project.

Stop the game and wait for downloads, setup and file operations before changing
its project. Another installed project's entry is never replaced. If the selected
project already has local backup or look data, the change is refused so that data
can be reviewed first.
