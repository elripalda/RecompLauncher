# RecompLauncher 0.90 Beta 17

- **Smoother controller navigation.** Cleaner highlights that fit what's selected, covers picked straight from their artwork, and quicker moves around every page.
- **Pick where save backups go.** Keep the copies of your saves in any folder: another drive, a NAS, or one that Drive, OneDrive or Dropbox keeps in sync.
- **Smarter game scanning.** One version of each game goes into your Library, it stays the way you set it up, and disc images are matched to the right console.
- **Better Linux support**, including Flatpak builds and more Windows builds running through Proton.
- **Library sort is remembered** between launches.
- **Better crash help and setup checks.**
- **General fixes and optimization.**

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
