# RecompLauncher 0.90 Beta 16

- **Key rebinding.** Recomps that support it let you change their keys, mouse buttons and controller buttons in Game Settings.
- **Controller navigation.** The whole launcher works with a controller: D-pad or stick to move, A to pick, B to go back, LB and RB to switch pages.
- **Settings stay in sync.** Changes made in a game's own menu show on its page as soon as it closes.
- **GitLab projects.** Recomps hosted on GitLab install, update and add from a link, the same as GitHub ones.
- **Opens On: Discover.** Discover can now be the page the launcher opens on.
- **Smoother desktop.** Fixes for stutter some PCs saw while the launcher was open, and covers and logos load more reliably.
- **Better setup checks and crash help**, including Steam Link and Remote Play on Linux.
- **General fixes and optimization.**

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
