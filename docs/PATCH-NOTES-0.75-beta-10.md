# RecompLauncher 0.75 Beta 10

Fixes from your Beta reports, and updates that show up the moment they're out.

- **Updates the moment they drop.** When a new RecompLauncher or an update for one of your games goes out, the launcher hears about it right away while it's open, so you don't have to wait or restart to find it.
- **Update count on Downloads.** The Downloads tab shows how many updates are ready, and the launcher's own update is listed there with your games.
- **Recomps with their own installer or setup.** Some recomps come as an installer, or need their own setup run once before the game. The first time you press Play, that setup opens for you. Follow its steps and the game is ready. For an installer, the launcher finds where the game went and plays it from there, with the options its shortcut uses.
- **The right program for games with a launcher.** Games that ship their own launcher next to the engine now start through it, instead of the engine on its own, including launchers named with the game's initials.
- **Launch scripts.** When a release starts its game with a script named for it, the launcher uses that so the game gets its options.
- **Pick your game files, and the launcher finds them.** When a game asks for the folder with your copy, the crash window has a Pick your game files button. Pick the folder you put the game in, and the launcher finds the right one inside it.
- **Launch options with folders in them.** A folder with spaces in its name works in Launch options without quotes around it. If a game doesn't understand its Launch options, the crash window says so and can clear them for you.
- **Graphics driver problems explained.** When a game can't start because your graphics card or driver doesn't have DirectX 12 or Vulkan, the crash window says so and tells you to update your driver.
- **Games that need your files passed to them.** When a recomp shows how it wants to be started, the crash window explains it and takes you straight to its Launch options.
- **The crash window says when your copy is the wrong version.** If a game says your copy doesn't match (a different region or revision), the window tells you to check which version its developer needs.
- **Closing a game's console window isn't a crash.** Quitting a game by closing its console no longer opens the crash window.

Already installed one of these? Just press Play: the launcher checks it again the first time.

One-click setup is coming game by game. We're working with each recomp's developer to get their game ready for it, so some will still need a step or two from you for now. Thanks for bearing with us. Every build gets closer.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
