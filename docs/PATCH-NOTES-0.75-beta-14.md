# RecompLauncher 0.75 Beta 14

- **Easy Setup filter.** Discover has a new Easy Setup switch, and Big Picture has an Easy Setup chip, so you can see every recomp the launcher sets up for you in one place.
- **Cleaner Discover.** The filters now sit in two tidy rows, and Discover shows the recomps made for your PC automatically.
- **Clear history.** Downloads and Updates each get a Clear history button, so you can start fresh whenever you like.
- **Polished text everywhere.** Headings, buttons and labels across the launcher are properly capitalized, and dates read "Today" and "Yesterday".
- **Smarter setup checks.** When you insert your copy, the launcher now checks it's the right region and that the disc image can actually be read, and tells you right there if it isn't.
- **Better help when a game closes.**
  - A game whose files moved now lets you pick the new folder in one click.
  - Missing system files point you straight to the Visual C++ download.
  - Graphics hiccups point you to the right switch in Game settings.
- **More Easy Setup.** Another recomp joins the one-click setup list.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
