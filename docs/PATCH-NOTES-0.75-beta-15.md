# RecompLauncher 0.75 Beta 15

- **While Playing settings.** A new page in Settings lets you choose how the launcher behaves during a game:
  - Quick Menu Over Games, on or off.
  - Minimize the Launcher While Playing.
  - Lighter Launcher, with still pictures and no animations.
  - Handhelds like the ROG Ally, Legion Go and Steam Deck get the lightest setup automatically.
- **Smoother PC while the launcher is open.** Controllers are now looked for only when it matters, so your mouse and games stay smooth.
- **DualSense over Bluetooth.** Every button works wirelessly in Big Picture mode, L1 and R1 included.
- **Faster file picking.** Picking files and folders now opens Windows' own picker: instant, reaches every folder and takes a pasted path. The launcher's own browser is still there in Settings, now with AppData and a box to paste a path into.
- **Add any game.** Games the launcher doesn't know yet can go in your Library too. Add Games You Have lists every game folder it finds, and you pick which game each one is or add it as your own.
- **Choose where a game saves.** On the Saves page, press Change to point backups and cloud saves at the folder your game really uses.
- **Multiplayer filter.** Discover and Big Picture now have a Multiplayer filter for recomps with split-screen, co-op or online play.
- **Check for Updates.** A button in Settings checks every game for updates right away, and installed games now recognize the version you already have.
- **Quicker updates.** Backing up your saves before an update is much faster, and you can press Skip if it ever takes too long.
- **Smarter N64 setup.**
  - ROMs in any format (.z64, .n64 or .v64) work.
  - The launcher checks it's the right game and version as soon as you pick it.
- **More Easy Setup.**
  - Two more recomps join the one-click setup list.
  - Clearer setup steps for PS3 ports, plus a How to Set Up section on game pages.
- **Steam stays in sync.** Games started from Steam now show you as in game for the whole session.
- **Better help when a game closes.**
  - New hints for .NET, graphics driver resets and Vulkan, games installed in protected folders, and PS3 EBOOTs.
  - A Play Without the Look button when a game doesn't get along with ReShade.
  - Crash reports now include the right log from that session.
- **Uninstall that finishes the job.** Uninstalling now deletes the game's folder even when files are marked read-only, tells you if anything is still in use, and opens the game's own uninstaller when its installer put it somewhere else.
- **Library folders.** You can remove any library folder; the games in it stay in your Library.
- **Start Server.** Community servers now say Start Server instead of Play.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
