# RecompLauncher 0.90 Beta 4

- **Plugins.** Add pages and tools made by other people from Settings → Plugins. Each one runs walled off from the rest of the launcher, shows what it can do before you install it, and asks you before it downloads or installs anything and the first time it connects to a site. Turn one off, or all of them at once, any time.
- **Make your own plugin.** The developer guide and an example plugin are on GitHub.
- **Your sidebar, your way.** Settings → Appearance → Sidebar: hide sections and put them in the order you like. Big Picture follows along.
- **Smarter Add From GitHub.** The launcher reads the repo to work out the game and its console, checks Discover first, and shows you the details to check before adding it. Add your own free SteamGridDB key in Settings → Games and folders for covers and backgrounds.
- **Edit Game Info.** Change the name, game, console and art of a game you added yourself, from its right-click menu.
- **Pick your region.** When a release has a build for each region, you choose which one, and can switch later with Change Build.
- **Zipped copies work.** Pick a .7z or .zip as your game copy and the launcher unpacks it for you.
- **Fewer false virus warnings.** RecompLauncher now asks Windows for what it needs directly, and we cleaned up the wording that antivirus tools were misreading.
- **Sign-in kept by Windows.** Your sign-in now lives in Windows' Credential Manager. Sign in once more after updating.
- **Installs that hang on.** If Windows or an antivirus is holding a file while a game installs, the launcher waits and tries again.
- **Admin prompts that show up.** Game uninstallers that need administrator rights now get Windows' prompt.
- **Linux.** Windows games running through Proton now find your game copy.

We're in the process of getting RecompLauncher officially signed. Thanks for your patience, and for being part of the RecompLauncher family.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
