# RecompLauncher 0.75 Beta 11

The launcher now knows how every recomp in the catalog starts.

- **One-click play for more recomps.** We went through every recomp in the catalog, its release and its instructions, and wrote down how each one boots: which program to start, whether its setup has to run first, and where your copy of the game goes. Play now does exactly that instead of guessing.
- **Set up your copy once.** For recomps that read your game from a folder or need it passed to them, the launcher asks for your copy the first time, checks it, and puts it where the game reads it. A ROM is renamed to what the game expects.
- **Before you play.** When a recomp needs something only you can do (a decrypted file, an update from your console, build tools), its page says so up front.
- **Games that ask questions in their own window.** Recomps that ask you to type an answer the first time now show their questions.
- **Games that close fine and stumble on the way out** no longer bring up the crash window.
- **The crash window says when your copy is the wrong region.**

Also in the last betas:

- **Updates the moment they drop**, and a count of updates ready on the Downloads tab.
- **Recomps with their own installer or setup** open it on the first Play, and the launcher finds the game afterwards.
- **Launch options with folders in them** work without quotes, and the crash window can clear options a game doesn't understand.
- **Graphics driver problems explained** in the crash window.

One-click setup keeps improving game by game. We're working with each recomp's developer to get their game ready for it, so some will still need a step or two from you for now. Thanks for bearing with us. Every build gets closer.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
