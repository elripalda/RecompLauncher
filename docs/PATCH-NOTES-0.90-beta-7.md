# RecompLauncher 0.90 Beta 7

- **Set Up By Hand.** If a game still won't start the launcher's way, point it at the program and your game files yourself, and say how the game gets them: in its folder, on the command line, or the game asks. Find it under Manage in the right-click menu, in Troubleshoot, or under a setup that didn't work.
- **Pick your build.** When a release comes as more than one kind (an AppImage and a plain folder, a portable zip and an installer, 32-bit too), you choose the first time, with the usual one marked. Updates keep the kind you picked, and Change Build lists them all.
- **Troubleshoot digs deeper.** It finds the files a game needs that aren't on your PC and says what to install, spots a game folder inside OneDrive, and hears a game saying it was given the wrong files. A missing program you picked by hand gets its own fix.
- **Game files one folder off.** Pick the folder around your game files, or one inside them, and the launcher finds the right one.
- **Linux builds start right.** A game with a build per region starts the one you have, and a Linux start script is only used when there's a Linux program beside it.
- **Looks show up more often.** On Windows a Look tries both ways in first, and Troubleshoot can let it try both again.
- **Copy what you see.** Descriptions, paths, errors and Troubleshoot results can be selected and copied.
- **Clearer when a drive is gone.** If your library is on a drive that isn't connected, the launcher says so.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
