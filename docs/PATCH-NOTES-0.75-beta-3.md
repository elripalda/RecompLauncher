# RecompLauncher 0.75 Beta 3

Fixes from your Beta reports.

- **Play in Big Picture mode starts the game in front.** The launcher steps aside when a game starts from Big Picture mode, so the game's window (or its first-time setup) isn't hidden behind it. It comes back when you close the game.
- **Rows in Big Picture mode scroll again.** Moving across Just added, Most played and the other rows keeps the game you're on in view.
- **The folder picker looks right again.** Folder names line up on the left, and "Use this folder" picks the folder you have open.
- **The crash window says when game files are missing.** If a game closes because it can't find a file from your copy of the game, the window names the file and tells you to put your game files where its developer says.
- **Crash reports now say why.** When a game closes right after it starts, the launcher keeps what the game printed and shows it in the crash window. Sending the report includes it, so we can see what went wrong.
- **Save backups can't get stuck anymore.** If a game's save folder turns out to be huge (a cache or game data instead of saves), the launcher tells you instead of spinning forever.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
