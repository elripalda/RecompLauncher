# RecompLauncher 0.90 Beta 22

- **Smarter game setup.** Your game files are found even when they're a folder off, and if something's missing, the launcher tells you which files to look for.
- **A more helpful crash window.** When a game starts without its files, set them up in one press. Laptops with two graphics cards can switch a game to the faster one. And if a game closes that way on its own every time, tell the launcher you closed it yourself.
- **Starts the right program** more often, and tells you when a game needs Python or a newer Visual C++.
- **Better on Steam Deck.** More Windows games start through Proton.
- **General fixes and optimization.**

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
