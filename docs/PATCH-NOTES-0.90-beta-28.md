# RecompLauncher 0.90 Beta 28

- **Controllers through SDL 3** on Windows, Linux and Mac: one system for every pad, and quicker presses while you play. — Added by @Xarishark ([#41](https://github.com/elripalda/RecompLauncher/pull/41), [#44](https://github.com/elripalda/RecompLauncher/pull/44)).
- **Switch 2 packages** are recognized by their build. — Added by @Xarishark ([#39](https://github.com/elripalda/RecompLauncher/pull/39)).
- **A tidier game page.** Your copy of the game shows as one line, with everything found in a list you can open, and a new Launcher Support checklist shows what each recomp can do. — Added by @elripalda.
- **Clearer crash windows,** with what an error means and the game's own last error. — Improved by @elripalda.
- **Setup checks** for recomps that build on your PC, and a heads-up when a game now installs differently. — Added by @elripalda.
- **General fixes and optimization.** — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
