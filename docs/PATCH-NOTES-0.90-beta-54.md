# RecompLauncher 0.90 Beta 54

- **Pause Updates for any game from its menu, on the desktop and in Big Picture: it stays on its version, and its page says when a new one is out.** — Added by @elripalda.
- **Free Up Space: when a game no longer needs your copy to play, it can go to the Recycle Bin from the Your Copy card.** — Added by @elripalda.
- **Move Build: a game that builds into a folder of its own can move that build to the drive you pick.** — Added by @elripalda.
- **Moving a game to a place where you already copied it uses the files already there.** — Added by @elripalda.
- **Big Picture and installs sent from the website ask where the game goes, like the desktop does.** — Fixed by @elripalda.
- **The launcher opens faster: the scan of your game folders no longer holds up the window.** — Improved by @elripalda.
- **Easy Setup says what a game's setup reported when it stops, and picking the wrong folder says what to pick instead.** — Improved by @elripalda ([#218](https://github.com/elripalda/RecompLauncher/issues/218)).
- **A game that says its own setup hasn't run gets it on the next Play.** — Fixed by @elripalda.
- **On Windows, a launcher that can't open its window says why, such as a missing WebView2.** — Improved by @elripalda ([#222](https://github.com/elripalda/RecompLauncher/issues/222)).
- **A list that points at a 32-bit ARM build installs the build for your PC.** — Fixed by @KevinBonnoron ([#224](https://github.com/elripalda/RecompLauncher/pull/224)).
- **Settings can hide the Big Picture button in the sidebar.** — Added by @Xarishark ([#226](https://github.com/elripalda/RecompLauncher/pull/226)).
- **Settings can give this PC a name, shown next to its saves.** — Added by @Xarishark ([#225](https://github.com/elripalda/RecompLauncher/pull/225)).
- **Set Up Again sits beside Play, and new setup options are asked about once.** — Added by @Xarishark ([#230](https://github.com/elripalda/RecompLauncher/pull/230)).
- **Games open on the monitor picked for Big Picture, and the quick menu follows the game's monitor.** — Added by @Junkasss ([#220](https://github.com/elripalda/RecompLauncher/pull/220)).

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
