# Supported games

The full, up-to-date list lives on **[recomplauncher.com](https://recomplauncher.com)**, and the same list is in the launcher's **Discover** tab. New recomps are added every day, so a copy here would be out of date by tomorrow.

## What the labels mean

| Label | What it means |
|---|---|
| **Easy Setup** | Point the launcher at your disc image or game folder and it sets everything up. Each game lists the file types it accepts. |
| **Setup Required** | The recomp needs a few manual steps first. The game's page shows a yellow **Set Up** button that walks you through them. |
| **Plays great** | Most players who sent a report say it runs well. |
| **Versions** | More than one recomp of the same game. They show as one game, and you can switch between them or keep a few installed. |
| **Windows / Linux / Mac** | The systems the developer makes builds for. Discover only shows builds for your system. |

## What every game needs

Your own copy of the original game. RecompLauncher never includes or downloads game files. Each game's page says exactly which version of the game the recomp needs under **Before You Play**.

## Your game isn't listed?

Submit it on [recomplauncher.com](https://recomplauncher.com). If you're the developer, the [developer guide](DEVELOPERS.md) shows how to add one-click setup with a `recomplauncher.json`.
