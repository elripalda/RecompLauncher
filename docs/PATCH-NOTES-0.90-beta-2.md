# RecompLauncher 0.90 Beta 2

- **Start With.** Hold Play to pick which of a recomp's programs starts this time. In Big Picture mode it's in the game's menu. A normal press of Play still starts the usual one.
- **Big Picture on Linux.** Big Picture mode opens properly from the AppImage, straight into Home.
- **Games start on Linux.** Recomps started from the AppImage now run just like they do on their own, and so do their setups, shortcuts and updates.
- **Closing means closed.** With the tray turned off, closing the window quits RecompLauncher properly, so it opens straight back up the next time you click it.
- **Time to Update.** When a version is too old to keep up with the recomps, the launcher says so and updates in one click.
- **More graphics settings.** Games whose settings file is named a little differently now show their settings.
- **Your disc, handed over.** One more recomp gets your disc image the moment it starts, on Windows and Linux.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
