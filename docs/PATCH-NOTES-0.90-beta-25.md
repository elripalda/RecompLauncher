# RecompLauncher 0.90 Beta 25

- **Easy Install.** Games with Easy Setup get a green Easy Install button, and setup shows exactly which file types each game takes. — Improved by @elripalda.
- **Open games from the website.** Open in RecompLauncher on recomplauncher.com takes you straight to the game's page. — Added by @elripalda.
- **Pick the right project.** Point an installed game at the project it really belongs to, or keep it untracked. — Added by @Xarishark ([#26](https://github.com/elripalda/RecompLauncher/pull/26)).
- **A drive light for Easy Setup.** — Added by @Xarishark ([#33](https://github.com/elripalda/RecompLauncher/pull/33)).
- **Shaders.** A cleaner Shaders tab, with every shader and its preview on one screen. — Improved by @elripalda.
- **A tidier game page.** Add to Steam, Add to Desktop, GitHub and Report a Problem are up top with clear labels, and the page keeps a comfortable width on ultrawide screens. — Improved by @elripalda.
- **Nintendo Switch 2 recomps**, and a Feature Complete label for finished projects. — Added by @elripalda.
- **More Mac games** install, including ones released as disk images. — Improved by @elripalda.
- **RAR and 7z games on Mac**, and game ZIPs packed beside other files. — Added by @Xarishark ([#37](https://github.com/elripalda/RecompLauncher/pull/37)).
- **Linux fixes** for Big Picture, NVIDIA on Wayland and umu-launcher, and steadier downloads when GitHub is busy. — Fixed by @elripalda.
- **General fixes and optimization.** — Improved by @elripalda.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
