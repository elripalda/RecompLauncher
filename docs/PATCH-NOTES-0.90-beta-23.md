# RecompLauncher 0.90 Beta 23

- **Fewer "DLL too old" crashes.** The launcher finds old files a game came with and moves them aside in one press, and tells you when your graphics driver needs an update.
- **Clearer advice when files are missing.** If a game builds them itself from your copy, the crash window takes you straight to setting it up.
- **Better on Linux and Steam Deck.** Installed games stay on the right build, games set up on Windows find their program, and Add to Steam waits for Steam to fully close.
- **Steadier downloads** when GitHub is busy.
- **Your game copy is kept safe** when you uninstall a game it was stored in.
- **General fixes and optimization.**

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
