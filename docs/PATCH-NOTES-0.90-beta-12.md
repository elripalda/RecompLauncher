# RecompLauncher 0.90 Beta 12

- **Big downloads stay fast.** Plugin downloads from sites that slow each connection down after the first few megabytes now keep their speed all the way to the end. The file comes down in small pieces over several connections at once, and a connection that drags gets swapped for a fresh one.
- **Every save gets backed up.** Saves kept as .bin files, common in Xbox ports, are backed up and synced like the rest.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
