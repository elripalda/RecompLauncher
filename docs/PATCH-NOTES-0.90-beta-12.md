# RecompLauncher 0.90 Beta 12

- **Smoother on Linux and Steam Deck.** The window stays responsive while the launcher looks through a game's files, scrolling glides, and the soft glows are lighter to draw. NVIDIA and AppImage setups that showed a blank window draw the launcher properly now.
- **GE-Proton in one press.** On Linux, Settings → General has a GE-Proton button that grabs the newest one and sets it up. Windows recomps play through it right away.
- **See where a recomp runs.** Small Windows, Linux and Mac marks sit under every cover, and Discover has a new Runs On filter. On Linux, Windows-only recomps are marked as playing through Proton.
- **READMEs on game pages.** A recomp's README from its GitHub is on its page now, folded away until you open it.
- **Steam Controller support.** The launcher picks up a Steam Controller, and on a Steam Deck the button prompts match the Deck.
- **Add to Steam from Big Picture settings.** The Add to Steam button in Settings → Big Picture mode does its job now.
- **Big Picture mode opens properly.** It no longer comes up as a blank screen with only sound on some setups.
- **Launcher updates that didn't stick.** If an update downloads but doesn't install, the launcher tells you next time and can run its installer again.
- **Starts the right program.** Picking a game's setup as its program runs the setup, Troubleshoot warns when a game is set to start one of its tools, and Linux start scripts without a #! line run now.
- **Your disc reaches more Linux builds.** Linux builds named differently from their Windows version get your disc image too.
- **Clearer errors.** When Windows blocks an install with "access denied", or a Linux build is made for another processor, the launcher says what's going on and what to do.
- **Every save gets backed up.** Saves kept as .bin files, common in Xbox ports, are backed up and synced like the rest.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
