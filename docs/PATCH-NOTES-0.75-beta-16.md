# RecompLauncher 0.75 Beta 16

- **Your own covers.** Right-click any game and choose Set a Cover to give it the picture you like. Games you added yourself finally get proper art.
- **Favorites.** Star your favorite games from their menu. They get their own filter in the Library and their own row on Home.
- **Search from Home.** Start typing on Home and it takes you straight to the results.
- **Library filters.** Filter the Library by console once you have games from more than one.
- **Update All.** One button in the Library updates every game that has an update.
- **Easier manual adding.** When you add a game yourself, you can type to find it in the list.
- **Discord status.** Discord now shows the game you're playing, with its cover, play time and a link to RecompLauncher.
- **Every format, right away.** Picking your copy shows all the formats for that console: N64 ROMs in .z64, .n64 or .v64, and every disc image type.
- **Smarter setup.**
  - Disc images in .bin/.cue now bring their tracks along.
  - Your copy is checked again when you press Play, so a wrong one is caught before the game starts.
  - More recomps get the right setup steps.
- **Community servers.** Starting a server for the first time now tells you to fill in its settings file, with a button to open its folder.

Keep the logs coming from the crash window and Settings → Beta. Every one helps.
