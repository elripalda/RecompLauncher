# RecompLauncher 0.75 Beta 4

New from your Beta reports.

- **Quicker ways out of Big Picture mode.** Press B (or Esc) on Home and pick Leave Big Picture mode, or hold Menu on your controller for a second. F11 on the keyboard switches between the desktop view and Big Picture mode both ways.
- **A game's server isn't started as the game.** When a download has a server program for hosting online games, the launcher won't pick it as the game to start.

Everything from Beta 3 is in too: games start in front from Big Picture mode, rows scroll, the folder picker looks right, and the crash window says when game files are missing.

Keep the reports coming from the crash window and Settings → Beta. Every one helps.
