# Credits

## The recomps

Every game in RecompLauncher is made by its own developer, and all the credit for the games goes to them. Each game's page links to the developer's GitHub, with their license and their own credits.

## Contributors

Thanks to everyone who has sent code, translations, bug reports and logs. You can see everyone who has contributed code on the [contributors page](https://github.com/elripalda/RecompLauncher/graphs/contributors).

## Built with

- [Tauri](https://tauri.app), the app framework
- [SDL 3](https://www.libsdl.org) for controllers
- [Rust](https://www.rust-lang.org) crates including tokio, reqwest, serde, zip, sevenz-rust, unrar, backhand and image. The full list is in [src-tauri/Cargo.toml](src-tauri/Cargo.toml).
- [Archivo](https://fonts.google.com/specimen/Archivo) and [Figtree](https://fonts.google.com/specimen/Figtree), under the SIL Open Font License

## Tools it works with

The launcher can set up and use these. Each belongs to its own project and keeps its own license.

- [ReShade](https://reshade.me) and [vkBasalt](https://github.com/DadSchoorse/vkBasalt) for Looks (screen effects)
- [umu-run](https://github.com/Open-Wine-Components/umu-launcher) and [GE-Proton](https://github.com/GloriousEggroll/proton-ge-custom) for Windows recomps on Linux
- [SteamGridDB](https://www.steamgriddb.com) for cover art, with your own API key

RecompLauncher isn't affiliated with or endorsed by any game's makers or platform holders.
